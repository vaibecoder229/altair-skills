# Список покупок

Постоянный список покупок в файле.

## Фразы
- добавь молоко в список покупок
- что мне купить
- убери хлеб из списка
- очисти список покупок

## Как выполнять
1. Файл: `Документы\Altair-список-покупок.md` (заголовок `# Список покупок`).
2. «Добавь X» — прочитай файл (нет — создай), допиши `- X`, без дублей (сравнивай без учёта регистра).
3. «Что купить» — прочитай и выведи нумерованным списком; пусто — скажи «список пуст».
4. «Убери X» — удали строку с совпадением, подтверди.
5. «Очисти список» — оставь только заголовок.
